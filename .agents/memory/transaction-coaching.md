---
name: Transaction coaching transparency
description: Product decision about how Bassera labels transaction advice without a live AI service.
---

For transaction feedback, do not describe deterministic, entry-specific coaching as live AI analysis. Clearly label it as local guidance until a real service and user consent for sharing financial details are in place.

**Why:** The user wants a coach avatar that analyzes amount, category, and feeling, but a convincing avatar should not imply private financial data was sent to an AI system when no such integration exists.

**How to apply:** When expanding coaching, preserve the distinction between local tips and generated analysis. If connecting an AI provider, obtain consent before transmitting transactions and provide a local fallback.
